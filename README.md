# Bitácora

Bitácora es una guía conversacional para explorar oportunidades de emprendimiento sin decidir por vos. Puede partir de tu experiencia, una curiosidad, una idea que viste afuera o de no tener todavía un tema.

## Uso

Abrí esta carpeta con tu asistente de código compatible y empezá a conversar. El protocolo principal está en `AGENTS.md`.

La plantilla para guardar una exploración propia está en `bitacora/PLANTILLA.md`. Las guías de contraste y memoria se consultan solo cuando hacen falta.

## Privacidad

No guardes nombres, datos de contacto, empleadores ni otros datos identificables en la bitácora. Usá una descripción general confirmada por la persona.
